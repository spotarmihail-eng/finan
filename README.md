# Умные финансы

Персональный финансовый менеджер в виде Windows-приложения.

## Сборка Windows EXE

Проект использует Electron и electron-builder. GitHub Actions автоматически запускает сборку при push в ветку `main`. Сборку также можно запустить вручную во вкладке **Actions → Build Windows EXE → Run workflow**.

После успешной сборки EXE-файлы доступны в **Actions → выбранный запуск → Artifacts** (хранятся 30 дней).

## Важный шаг: добавить HTML приложения

Сейчас в репозитории подготовлена оболочка Electron и автоматический workflow, но исходный HTML самого финансового приложения ещё не добавлен.

Поместите файл приложения по пути:

```
app/index.html
```

После добавления файла и отправки изменений в `main` GitHub Actions соберёт:
- установщик Windows `.exe` (NSIS);
- portable-версию `.exe`, которую можно запускать без установки.

## Локальный запуск

```bash
npm install
npm start
```

## Локальная сборка

```bash
npm run dist
```
